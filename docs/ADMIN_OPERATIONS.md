# Moderation console

The private-pilot operator console is served by the API at `/admin`. It uses the existing v1 authentication and moderation endpoints. Start the API, register an adult account, then grant that account the admin role with `docker compose exec workspace python scripts/grant_admin.py EMAIL`. Sign in at `http://localhost:8000/admin` for local development; use a trusted HTTPS endpoint outside localhost.

The console lists open or resolved cases in priority order, loads later pages, opens manual cases for an existing place ID, and shows the source record, current place/review context, private case material, and decision history. It supports every action accepted by `DecisionIn`: publish, reject, merge, verify, set status, hide/restore/correct/merge places, hide/restore reviews, hide confirmations, resolve, and approve deletion. Action-specific fields are shown as needed. Publishing a correction defaults to “Keep current status”, which keeps the place's status and evidence unless the kind stops being designated or the pin moves more than 50 m. Correction and place actions send the current place version; a `409` reloads the case so the operator can review changes before retrying. API errors include the request ID for diagnosis.

The console keeps the bearer token in tab-scoped session storage and clears it on sign-out or `401`. The `/admin` page has a restrictive content security policy, no-store and no-referrer headers. Private fields are hidden behind an explicit reveal control; audit snapshots are inside closed disclosure panels. Access is enforced by the API on every private request. Operators should close or sign out of the tab when finished and should avoid copying private evidence into public source summaries. The frontend does not upload files; evidence is entered as text into the existing decision API.

This is an internal workflow for the private pilot. Hosting access controls, HTTPS, admin account recovery, and operator training belong to the pilot operations gate. The console does not make evidence or legal-status decisions for an operator, and it does not publish real places without an explicit admin decision.
